# А9 Арена · 3D

Интерактивная 3D-демонстрация многофункционального спортивно-образовательного комплекса
«А9 Арена» (Московская обл., г. Истра, д. Покровское).

Статичный сайт-вьювер на Three.js: вращение сцены, день/вечер, снимок ракурса в PNG,
карточки технико-экономических показателей по объектам, скачивание исходной 3D-модели.

## Состав

| Файл | Описание |
|---|---|
| `index.html` | страница вьювера |
| `assets/index-x0-_fsx1.js` | JS-бандл (Three.js) |
| `assets/index-C2z8SIBk.css` | стили |
| `assets/A9_Arena_Hero.png` | постер-заставка |
| `assets/A9_Arena.glb` | 3D-модель, 54,2 МБ (766 объектов, 944 тыс. треугольников) |
| `assets/A9_Arena.blend` | исходник модели для Blender, 36,9 МБ |
| `assets/model-stats.json` | статистика модели |

## Запуск локально

Из-за ES-модулей страница требует статический сервер (двойной клик по index.html не работает):

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Публикация на GitHub Pages

Репозиторий готов к GitHub Pages: все пути относительные.
Settings → Pages → Source: Deploy from a branch → `main` / root.
Сайт будет доступен по адресу `https://<ваш-логин>.github.io/a9-arena-istra/`.

> Файлы `A9_Arena.glb` (54 МБ) и `A9_Arena.blend` (37 МБ) превышают рекомендуемый
> лимит GitHub в 50 МБ, но ниже жёсткого лимита в 100 МБ — пуш пройдёт с предупреждением.
